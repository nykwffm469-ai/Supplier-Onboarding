Demo Script

Two roles, one complete story

An 8-minute walkthrough that covers the full supplier onboarding lifecycle from first access request to final review.

Supplier
  1. Sign in via demo login as Alex Supplier
  2. Review onboarding progress on the dashboard
  3. Complete company profile with identifiers
  4. Add manufacturing capabilities
  5. Upload and track ISO certifications
  6. Review credit standing and history
  7. Complete the assigned onboarding questionnaire
  8. Return to dashboard — watch completion percentage rise
Reviewer
  1. Switch to Riley Reviewer account
  2. View executive dashboard — KPI cards, pending queue, trends
  3. Open Admin → Access Requests
  4. Approve Morgan Supply from Northwind Components
  5. Return to dashboard — see pending count decrement
  6. Open Admin → Theme Studio
  7. Switch to CAT Industrial — full rebrand in one click
  8. Export theme pack JSON for the next demo
Pro tip: Before any demo, open the Test Center and click Reset Demo Story Data to restore all seeded content to its baseline state.
